
# CodeOrbit To-Do List

A simple and interactive To-Do List web application developed as part of the CodeOrbit internship program. It helps users organize daily activities by creating, updating, completing, and deleting tasks.

## 🚀 Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Store tasks using browser localStorage
- Retain saved tasks after refreshing the page
- Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## ⚙️ How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/MeharYG-dev/CodeOrbit-To-Do-List.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code.

## 💾 Data Storage

The application uses browser `localStorage` to save tasks locally. This allows tasks to remain available after the page is refreshed or reopened in the same browser.
